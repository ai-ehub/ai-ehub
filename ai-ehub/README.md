# AI EHub

Mentoring tools for small businesses, in four areas: Starting & Evaluating a Business, Pricing & Finance, Marketing & Operations, and Clarity & Decision.

To add in Claude: Customize > Plugins > Add > Add marketplace, then enter this repository's address and install each plugin. Turn on Sync automatically to receive updates.

**AI EHub Launcher:** https://claude.ai/artifact/51tYU7RsF8zUkDKzwxgNCv
One page listing every tool, when to use it, and a Copy button for its starter sentence. Paste it into a new Claude chat, add your details, and send.
