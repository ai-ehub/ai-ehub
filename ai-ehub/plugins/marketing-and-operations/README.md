# Marketing & Operations — AI EHub

Three mentoring tools for founders, small-business owners, and the mentors who work with them. Each tool is a skill: ask for it by name in any chat (for example, "Use Website Growth to…"), type "/" and pick it, or simply describe the task and Claude picks the matching tool.

| Tool | Use for | Try this prompt |
|---|---|---|
| **Marketing Strategist** | Marketing strategy & planning | "Use Marketing Strategist. Help me develop a marketing strategy for [business], targeting [customer] in [market]." |
| **Website Growth** | Website growth & conversion | "Use Website Growth. Audit this website for clarity, discoverability, and conversions: [URL and business goal]." |
| **Lean Operations** | Improve processes & SOPs | "Use Lean Operations. Help me improve this business workflow: [describe process, problem, and desired result]." |

## Built-in rules

- Facts, observations, assumptions, and recommendations are kept clearly separate; nothing is invented.
- Each conversation is treated as being about one business. Details from other mentees are never brought in.
- Substantial work ends with a client-shareable **Mentor Session Summary**.
- Marketing Strategist settles strategy before tactics and pauses after each major section. Lean Operations maps the current process and pauses before redesigning it. Website Growth reviews only pages it can actually see.
- Turn on web search, especially for Website Growth, which needs it to open the site.
